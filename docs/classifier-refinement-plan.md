# Priority Classifier — Refinement Plan

Roadmap for improving the importance classifier beyond the current **DistilBERT 0.57 macro-F1**
(vs the human holdout; baseline TF-IDF is 0.50). Ordered by expected ROI for our situation:
medium->high over-escalation is the dominant error, 959 LLM-labeled rows, an inherently subjective
task. See [`../AI_DOCS/priority-classifier.md`](../AI_DOCS/priority-classifier.md) for methodology.

## Data-grounded problems (measured on our training set)

- **24%** of rows are truncated at the 256-token limit -> real signal loss.
- **31%** carry forwarded / quoted thread history -> noise the model must see through.
- **6%** contain quoted-printable garbage (`=20`, soft-break `=`).
- Labels generated by **gemini-3.5-flash-lite** (the weakest tier) with a fuzzy medium/high boundary.

## Step 0 — Establish the human ceiling (do first)

- [ ] Have a second person independently label the 120-row holdout; compute human-human agreement
  (Cohen's kappa). If humans agree only ~65-70% on medium/high, 0.57 is near the ceiling and the
  target should be set accordingly. **This reframes every number below** and is cheap.

## Tier 1 — Data-centric (highest ROI)

- [ ] **Clean the text (top priority).** Extract the newest message only; strip quoted history,
  signatures, and forwarded headers; decode quoted-printable. Addresses the 24% truncation + 31%
  noise directly. Also fix it upstream in the listener's `getBody` so live email is clean too.
- [ ] **More labeled data**, weighted toward MEDIUM (the confused class): 959 -> 3000-5000 via
  `label_dataset.py`.
- [ ] **Stronger labeling model.** Relabel with `gemini-3.5-flash` / `-pro` instead of flash-lite for
  cleaner ground truth; optionally take 3 votes/email and keep high-agreement labels.
- [ ] **Clean the labels.** Run confident learning (`cleanlab`) to find and drop/relabel noisy
  training examples.
- [ ] **Better labeling prompt.** Add few-shot examples of hard medium/high cases to the rubric.

## Tier 2 — Task reformulation (targets medium->high)

- [ ] **Ordinal classification** (CORN/CORAL): treat low<medium<high as ordered so a medium->high
  error costs less than medium->low. Directly attacks the dominant error.
- [ ] **Threshold tuning:** the model over-predicts HIGH (precision 0.38) — raise the HIGH decision
  threshold on validation. Cheap, targeted.
- [ ] **Hierarchical / binary:** first "actionable vs not" (the core rubric question), then split.

## Tier 3 — Model-centric

- [ ] **Swap DistilBERT -> DeBERTa-v3-base** (SOTA for text classification; reliably beats DistilBERT).
- [ ] **Longer context:** raise `max_length` to 512 (pairs with text cleaning) to stop truncating 24%.
- [ ] **Hyperparameter sweep:** LR {1e-5..5e-5}, epochs, batch size. Diminishing returns.

## Tier 4 — Hybrid / advanced

- [ ] **Structured features:** concatenate the urgency lexicon, has-question-mark, imperative verbs,
  is-forwarded, length — inject the "actionable" cues the model misses.
- [ ] **LLM few-shot at inference:** Gemini as the classifier (best accuracy, worst ops — cost /
  latency / rate limits).
- [ ] **Knowledge distillation:** Gemini soft labels (probabilities) distilled into DistilBERT.

## Experiment results (vs the 120-row human holdout)

| Model | preprocessing | macro-F1 | medium F1 | high F1 |
|-------|---------------|----------|-----------|---------|
| TF-IDF + LogReg | raw | 0.50 | 0.48 | 0.43 |
| TF-IDF + LogReg | cleaned | 0.47 | - | - |
| DistilBERT | raw | **0.57** | 0.48 | 0.50 |
| DistilBERT | cleaned | 0.54 | 0.56 | 0.36 |
| RoBERTa-base | cleaned | 0.49 | 0.33 | 0.45 |

**Key finding:** every configuration lands in **0.47-0.57 — all inside the +/-9% confidence interval**
of a 120-sample holdout, so they are statistically indistinguishable. **Model capacity and text
preprocessing are not the bottleneck.** Cleaning shuffled errors (helped MEDIUM 0.48->0.56, hurt HIGH
0.50->0.36) rather than lifting overall accuracy. This points the remaining effort at the **label
signal and task subjectivity**, and at a **larger holdout** to shrink the confidence interval.

Best model retained: DistilBERT. Cleaning kept (correct engineering for live email — decodes
quoted-printable, strips quoted history — even though its accuracy effect is within noise).

## Recommended sequence

1. Human ceiling (Step 0).
2. Text cleaning (Tier 1) — likely the biggest single lift.
3. DeBERTa-v3 + max_length 512 (Tier 3) — reliable, low effort.
4. More MEDIUM-weighted data + label cleanup (Tier 1).
5. If still short: ordinal + threshold tuning (Tier 2).

**Realistic target:** steps 2-4 plausibly reach ~0.65-0.70; beyond that is likely the human ceiling
for a subjective task, which Step 0 confirms. Reporting *why* MEDIUM resists improvement is itself a
valid research finding.

## Outcome (final)

**Rubric-consistent relabeling broke the plateau: 0.57 -> 0.69 macro-F1** (RoBERTa, full-thread,
512 tokens, labels re-generated with the explicit boundary rubric). MEDIUM F1 rose 0.48 -> 0.68.
This revised the intermediate "inherent ceiling" reading: the binding constraint was **label
consistency**, and it was addressable. Live model is this RoBERTa checkpoint (`PRIORITY_MODEL=distilbert`).
